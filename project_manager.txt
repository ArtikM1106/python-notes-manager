Иван Морев — тестировщик.

Цель и актуальность
Сделать настольную программу для коротких текстовых записей, которые можно найти и обновить после перезапуска.

Задачи
Создать окно со списком и полем текста, реализовать сохранение, выбор, изменение и удаление записей, провести проверку действий.

Функциональные требования
«Новая» очищает редактор для следующей записи. Выбор строки открывает заметку. «Сохранить» добавляет новую заметку или обновляет выбранную. Пустой текст вызывает сообщение. «Удалить» сначала запрашивает подтверждение. «Выйти» закрывает окно. Данные загружаются при следующем запуске.

Нефункциональные требования
Работа в одном окне без интернета и сторонних пакетов. Сохранение в читаемом JSON рядом с программой. Сообщение при ошибке чтения или записи.

Технологии
Python 3 и Tkinter позволяют сделать приложение стандартными средствами. notes.py содержит интерфейс и действия, storage.py отвечает за чтение и запись.

Запуск: python notes.py
